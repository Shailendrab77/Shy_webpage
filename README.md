# Shy Webpage

A simple guestbook web app built with Vite and vanilla JavaScript.

## Run on your Windows PC

### Option 1: Double-click (easiest)

1. Install [Node.js](https://nodejs.org/) (LTS version) if you do not have it yet.
2. Extract the downloaded project folder.
3. Double-click `start-windows.bat`.
4. Open **http://localhost:5173** in Chrome or Edge.

### Option 2: Terminal

```bash
npm ci
npm run dev
```

Then open **http://localhost:5173** in your browser.

## Project structure

- `index.html` - page shell
- `src/main.js` - guestbook logic
- `src/style.css` - styles
- `vite.config.js` - dev server settings

## Other commands

```bash
npm run build    # create production files in dist/
npm run preview  # preview the production build
```
